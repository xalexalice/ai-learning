# RAG 综合项目交付表

本表是学习者工作表，不是已完成项目报告。先写真实输入与验收门槛；每项记录“未执行/通过/失败”、证据文件或日志位置及日期。示例身份和文档使用自制数据，不能粘贴私有资料或密钥。

## 范围与版本

| 项 | 填写要求 |
| --- | --- |
| 用户与任务 | 谁用、问什么、不支持哪些动作 |
| 数据许可与边界 | 来源、许可、公开/私有、允许处理范围 |
| 输入版本 | 文档 ID/版本、更新时间、删除和授权机制 |
| 实现版本 | 代码 commit、依赖、配置、模型/索引版本 |
| 目标与预算 | 质量/拒答、时延、流量、费用与运行环境 |

## 分阶段交付

| 阶段 | 最小产物 | 验收证据 |
| --- | --- | --- |
| 文档入库 | 解析、去重、切片、版本、删除/更新记录 | 固定输入的片段及元数据；坏文档行为 |
| 检索基线 | 关键词基线，相关片段标注 | 每题相关片段和检索列表 |
| 候选检索 | 向量/混合/重排按需增加 | 与基线同题比较，配置和错误 |
| 生成与证据 | 答案、引用、证据不足拒答 | 引用可定位；事实是否受来源支持 |
| 服务接口 | 请求/事件、超时、取消、重试、限流 | 断流、取消、超时及资源释放日志 |
| 权限与更新 | 可信身份、过滤、缓存失效和版本 | 下表用例逐项结果 |
| 交付与回滚 | README、配置示例、测试、运行/回滚 | 第二人能启动并复现；无真实密钥 |

## 边界用例

| 场景 | 预期检查 |
| --- | --- |
| 有依据且有权限 | 回答及引用正确、版本可追踪 |
| 没有依据 | 拒答或说明无法确定，不能编造引用 |
| 同租户不同用户 | 私有文档与缓存结果符合各自权限 |
| 不同租户同问题 | 数据和缓存隔离 |
| 文档 V1 更新为 V2 | 标明生效窗口，检查索引与缓存 |
| 授权撤销 | 窗口内及窗口后怎样阻止旧证据流出 |
| 文档删除 | 检索旧候选也不能返回已删除内容 |
| 失效事件丢失 | 发现、补偿和验证旧答案失效 |
| 文档中有恶意指令 | 将文档视为数据，不扩大工具权限 |
| 断流、取消、过载 | 结束状态真实，停止资源或明确残余 |

## 完成记录

每项保留实际结果而不是只打勾：场景 ID、输入版本、身份、运行 ID、预期、实际、成败、失败原因、修复与复测。填写评估报告后标记项目阶段；模型未执行的部分保留“未执行”。
