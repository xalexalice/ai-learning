# AI 开发与架构面试复盘表

用于学习检查，不是招聘标准。回答只使用自己真实负责的部分；设计练习、课程实验、团队项目和生产经验分别写清。

## 证据盘点

| 能力 | 四档自评 | 证据/缺口 |
| --- | --- | --- |
| 接口与服务 | 能解释 / 能实现 / 能复现验证 / 能说明生产取舍 | 代码、测试、故障或需要补的实验 |
| RAG 数据与引用 | 同上 | 语料、版本、逐题输出 |
| Agent 状态与工具 | 同上 | 工作流基线、轨迹、副作用恢复 |
| 评估与错误分析 | 同上 | 固定题集、分母、配对比较、局限 |
| 权限与缓存 | 同上 | 身份、撤权/删除、失效边界 |
| 容量与可靠性 | 同上 | 单位、实测、SLO、回滚与决策 |

## 一次演练

先用 5 分钟讲任务、个人贡献、数据流和结果，再用 10 分钟讨论一个故障或选择。允许调整时间；不用时间成绩替代技术证据。

| 记录项 | 内容 |
| --- | --- |
| 题目与约束 | 原始问题、澄清条件与不确定项 |
| 自己的回答 | 方案、代码/结果依据与局限 |
| 追问 | 权限、更新、失败、容量、费用与替代方案 |
| 未回答项 | 具体不知道的机制或缺证据 |
| 下一个动作 | 一个能验证缺口的阅读/代码/实验任务 |
| 复测日期 | 重答后有什么实质改善 |

## 六类题目入口

RAG 与适配选择；同问不同人缓存；流式超时和过载；20 QPS/5 秒容量；工具写入重试；候选相对基线的证据。题目细节见笔记 ai-interview-casebook，不假设这些是任何公司当前题库。

复核每条数字：是否实测、分母是什么、个人贡献是什么、能否独立复现、哪些边界尚未覆盖。阅读完成不能直接写为生产经验。
