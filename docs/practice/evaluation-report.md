# AI 项目评估报告工作表

复制本表后填写自己的实际运行。未执行字段明确写“未执行”，手算与假设单独标记。本站缓存实验的结果不能用作你的 RAG/agent 项目成绩。

## 运行清单

| 字段 | 需记录 |
| --- | --- |
| 任务与边界 | 用户、数据权限、支持与不支持范围 |
| 版本 | 代码 commit、题集/文档、模型/索引、提示/工具、配置 |
| 环境 | OS、运行时、硬件/服务、并发、日期与次数 |
| 题集 | 数量、采样、分类、标注与保留集；重复与泄漏检查 |
| 对照 | 基线、候选、唯一改动或无法拆分的改动 |
| 验收门槛 | 运行前确定；质量、权限、延迟与预算分开 |

## 逐题记录格式

| case ID | 类型/身份 | 预期依据或动作 | 基线实际 | 候选实际 | 判定及原因 |
| --- | --- | --- | --- | --- | --- |

正文输出、引用、检索列表、工具参数/结果和状态轨迹单独保存。不要公开敏感内容、凭据或真实用户标识。

## 指标与分母

| 指标 | 分子/分母或单位 | 本次必须说明 |
| --- | --- | --- |
| Recall@k | 召回的相关片段 / 标注相关片段 | 标注粒度、k、过滤条件 |
| 答案正确/证据支持 | 满足规则题数 / 对应 eligible 题数 | 规则、人工复核与无答案问题 |
| 权限与工具任务 | 符合预期的案例 / 此类别案例 | 越权拒绝可算预期成功，副作用单查 |
| 完整请求成功 | 正常结束且满足协议 / eligible 请求 | 流式开头成功不够；排除规则 |
| 延迟 | ms/s，首字与总耗时分别统计 | 样本、负载、分位数、失败是否纳入 |
| 费用 | 币种/单位，按尝试或成功任务 | 输入/输出、工具、检索、重试、基础设施 |

## 对照结论

记录相同 case 的成败配对和类别切片；若使用区间，说明估计方式与样本限制。LLM judge 记录其版本、提示、参数，与人工判定的分歧。多项同时改变，只能比较整体方案，不能给单个模块归功。

## 失败与局限

至少展开一例：输入与预期 → 实际输出/动作 → 定位依据 → 根因 → 改动 → 同题复测。写保留集表现、遗漏边界与适用范围。离线测试不能证明线上因果收益；没有真实费用/负载测试就不要填收益数字。
